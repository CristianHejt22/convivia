Recibí cada nuevo pedido con datos del cliente, productos y horario de entrega directamente en tu Telegram.

Obtenelo gratis en Telegram hablándole a @BotFather y enviando /newbot.

Para saber tu ID personal de Telegram, hablále a @userinfobot en Telegram.

💡 Instrucciones Rápidas para Dejarlo Funcionando en 1 Minuto:
  1. Abrí Telegram y creá tu bot enviando /newbot a @BotFather.
  2. Copiá el Token HTTP API y pegalo arriba.
  3. ¡Muy importante! Abrí una conversación con tu nuevo bot en Telegram y dale clic al botón INICIAR (/start).
  4. Ingresá tu Chat ID (lo averiguás en @userinfobot).
  5. Hacé clic en ⚡ Probar Envío al Bot para confirmar que recibís el mensaje al instante.
